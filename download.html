Install

Up and running in three steps

  1. 1

    Download

    Get the installer above. It's about 12 MB.

  2. 2

    Run the installer

    If Windows warns you, click More info, then Run anyway. The installer isn't signed by a company yet; updates after this are signed.

  3. 3

    Create a server

    Open Lodestone, pick a server type and press Create. Lodestone downloads Java and the server for you.

Requirements

Windows 10 or 11 (64-bit). Memory for your server: 2 GB for Vanilla, 4–8 GB for modpacks. Lodestone downloads the right Java for you.

Your friends

They don't need Lodestone, just Minecraft and your server's address. To help manage a server, they install Lodestone and use the password you give them.

Problems?
